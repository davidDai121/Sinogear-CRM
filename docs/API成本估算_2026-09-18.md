# 团队 API 成本估算（2026-09-18）

## 实际用量口径

只读统计本组织 contacts 关联的 messages，窗口为 America/Chicago 2026-09-04 至 09-18（不含 09-18 当天）。仅数据库聚合，无全量聊天正文导出。聚合快照在 `分析导出/API成本_2026-09-18/团队用量.json`。

近期量明显增长，因此预算用最近四个完整日 09-14～09-17：日均 664.25 条双向消息、386.75 条入站、277.5 条出站、176 个聊天联系人。将同客户连续入站且相邻间隔不超过 5 分钟的消息合成一轮，日均 239.5 轮，范围 191～293 轮；预算取每天 250 次生成，不按每个气泡各调用一次。

这是 CRM 已同步记录，不能保证覆盖每位销售全部 WhatsApp 聊天。库内总计 129,197 条消息，其中 7,187 条无 sent_at，不能分配到上述日期。不同来源可能仍有重复；五分钟归并也只是负载代理，不是产品应固定等待五分钟。当前 AI 调用日志仅各机器本地保存，不能从 tagged_ai_outbound 或新增草稿数推断团队真实生成次数。09-18 含开发验收，排除出日均量。

## 价格及假设

官方价格核对日期 2026-09-18，美元/百万 token，标准处理、非缓存输入：

| 模型 | 输入 | 输出 |
| --- | ---: | ---: |
| GPT-5.4 mini | 0.75 | 4.50 |
| GPT-5.6 Terra | 2.00 | 12.00 |
| GPT-5.6 Sol | 4.00 | 20.00 |

来源：[GPT-5.4 mini](https://developers.openai.com/api/docs/models/gpt-5.4-mini)、[官方标准价格](https://developers.openai.com/api/docs/pricing)。Sol 当前为促销价，官方注明至少持续至 2026-11-21。

人民币用 **1 USD=7.2 CNY 的预算换算假设**，不是实时汇率。假定每次 5,000～10,000 输入 token、1,000～2,000 总计费输出 token（必须包含推理消耗），含译文及简短内部结果；乘 1.3 作为重试和小型辅助调用预算。无需模型计算的报价算术仍在本地执行。未计入缓存优惠、搜索工具、图片/音频、WhatsApp/Meta/云服务费、税费及充值手续费。额外深度推理、频繁重写或大规模后台分析会超出此范围。

**该 token 范围是精简后的目标，不是当前已有实测。** 现有复杂订单约 9.6 万字符；字符不能直接当作 token。

## 预算结果

| 方案 | 50 次/天 | 250 次/天 | 250 次/天、30 天 |
| --- | ---: | ---: | ---: |
| GPT-5.4 mini | ¥3.86～7.72 | ¥19.30～38.61 | ¥579～1,158 |
| GPT-5.6 Terra | ¥10.30～20.59 | ¥51.48～102.96 | ¥1,544～3,089 |
| GPT-5.6 Sol | ¥18.72～37.44 | ¥93.60～187.20 | ¥2,808～5,616 |

经济型模型是否达到 Miles 的销售质量需用真实订单评估，不能只因便宜就默认全面替换。可先保留网页作为回退，API 从少量人工触发草稿开始；不启用自动发客户消息。若后续采用 90% mini + 10% Sol，同样假设每天 250 次约 ¥26.73～53.46。

若每次实际是 30,000～60,000 输入、2,000～4,000 计费输出，mini 每天 250 次约 ¥73.71～147.42，Terra 约 ¥196.56～393.12。这是长上下文情景，不是已测 token；说明需先瘦身再迁移，不能宣称目前直接切 API 每天只花几元。

公式：次数 × (输入 token × 输入价 + 计费输出 token × 输出价) / 1,000,000 × 7.2 × 1.3。
