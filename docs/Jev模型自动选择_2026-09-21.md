# CRM 模型选择接入

在客户卡片的 GPT 回复区选择“自动选择 · Jev／快速／深入”，然后照常生成或内部讨论。当前浏览器可用的 Custom GPT 映射：快速为 Instant / GPT-5.6 Sol，深入为 Pro / GPT-6 Pro。选择只影响计算模型，不改变销售员对应的 GPT 模板、客户会话、已批准资料、报价核算或跟进权限。

## 已实现

- CRM 将当前客户最新消息、近期对话和本单有关记忆组成有大小限制的判断输入；不把整个业务提示或全库发往 Jev。
- 扩展后台直接调用 TypeSafe 官方接口，不依赖本地试用页或 Codex 保持在线。
- 手动选择优先；报价/运费规则、长到需要截断的上下文保留深入档。明确仅翻译的本轮要求可交 Jev 判断，不被历史询价永久锁在深入档。
- Jev 缺失、超时或异常时选择深入档；网页切换无法核验时停止在发送前，并显示错误，不能把建议当作已用模型。
- 新建对话和续聊都在本轮自己的标签页发送前切换，核对实际模型提示；不会改其他正在使用的聊天。
- 运行中显示准备阶段和模型；取回/刷新恢复保存的实际模型。草稿仍由人工检查、填入和发送。
- 技能和普通 ChatGPT 入口暂沿用原模型，不声称支持其自动分流。后台定时跟进复核保持原配置，本轮不自动开启。
- 对从未激活的页面增加准备阶段的有限唤醒，沿用已有不抢焦点窗口机制与次数限制。模型切换有独立期限。

## 一次性连接

Chrome 的 Sino Gear CRM 扩展弹窗中新增 Jev 设置；填写 key 后验证官方模型列表并保存本浏览器。列表返回 `jev-latest` 等别名，不应要求它显示推理响应中的具体版本号。保存校验已针对该真实返回结构回归测试。

key 不进入源码、构建产物或客户页面，不通过状态消息回显；保存在扩展本地存储，不同步到团队数据库。自动分流的任务文字发往 TypeSafe 官方接口。只有扩展自身设置页能保存连接。

本轮浏览器工具策略阻止代理访问扩展设置页，因此由用户完成一次性密钥输入，未通过其他浏览器表面绕过限制。
