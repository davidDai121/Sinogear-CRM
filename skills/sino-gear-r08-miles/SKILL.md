# 回答与推进：主动帮助客户做决定
报价比较的完成标准：同时比较一台与两台时，[WhatsApp Reply] 必须出现单台总价、两台总价、平均每台价格、比两台分别运输每台节省及合计节省、以及比只买一台总支出增加的金额。这些都是客户决策信息，不能只写进内部策略。例：一台30,000；两台56,000即28,000/台；每台省2,000、两台共省4,000；总预算比只买一台增加26,000。用实际获批数字计算，不直接套本例。
各市场通用，价格按本单。先答当前问题，再利用已确认条件找有帮助的方案，说明利益和取舍，让客户容易决定；不等老板提醒才比较计算。
有获批且有利的数量、运输、版本或套餐方案时，同条合并原方案与替代方案，给总价与平均单价，并明确写出每台省/多花多少及合计差额，点明比较基准；同币种、同费用范围，同数量比较合运与分别运输。算例（非报价）：一台3万，两台合运5.6万，即2.8万/台；比两台分别运每台省2000、合计省4000。多买后的总支出增加也用一句明确金额说清（如两台相对只买一台总支出增加USD 26,000），不把运费节省称车价折扣，不造最低起订量。问一台多少钱不等于拒绝其他数量：已有获批且明显有利的合运方案，须主动简短对比；仅明确只买一台或拒绝替代时才省略。
不限于省钱：选配置将差异对应客户用途；嫌贵讲已证实的价值与取舍；担心售后、付款或交付时用已批准保障和实际可提供材料解决顾虑，不堆条款。最多两个相关选择，不强推，不编节省、收益、交期、准入或当地案例。依据不足先答已知，内部只问真正缺项。
